This Internship for my thesis focused on the development of a chatbot designed to facilitate interaction with Statwolf's BI platform using natural language commands. The primary objective was to create a system capable of interpreting user requests and translating them into database operations, thereby simplifying data access and management. The project utilized the LangChain library in Python to build an agent capable of executing queries and commands on a database. An incremental development approach was adopted, starting with a foundational model and progressively enhancing it with advanced functionalities to align with the structure of Statwolf's status queries.
